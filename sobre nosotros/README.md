# ECOM Advisory — Página "Sobre Nosotros"

Página web estática para la sección **Sobre Nosotros** de ECOM Advisory.

## 📁 Estructura del proyecto

```
sobre nosotros/
├── index.html              # Página principal
├── css/
│   └── styles.css          # Estilos premium (diseño oscuro moderno)
├── js/
│   └── main.js             # Interactividad y animaciones
├── assets/
│   └── images/             # Imágenes (foto del equipo, etc.)
└── README.md               # Este archivo
```

## 🚀 Cómo usar

1. Abre `index.html` en tu navegador (doble clic o con Live Server).
2. Las fuentes e iconos se cargan desde CDN (requiere internet).

## 🎨 Características

- Diseño oscuro premium con gradientes
- Sección Hero con partículas animadas
- Contadores de estadísticas animados
- Cards del equipo generados dinámicamente
- Formulario de contacto con validación
- Menú responsive para móviles
- Animaciones al hacer scroll (AOS nativo)
- Botón "volver arriba"

## 🛠️ Personalización

| Archivo | Qué cambiar |
|---|---|
| `js/main.js` | Datos del equipo (`teamMembers`) |
| `css/styles.css` | Colores (variables en `:root`) |
| `index.html` | Textos de misión, visión y valores |
| `assets/images/` | Foto del equipo (`team-photo.jpg`) |

## 📦 Dependencias (CDN)

- [Google Fonts](https://fonts.google.com/) — Inter + Syne
- [Font Awesome 6](https://fontawesome.com/) — Iconos
